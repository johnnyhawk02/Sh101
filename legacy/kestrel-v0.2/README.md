# Kestrel MS-1 v0.2 (the first prototype)

The first build, kept for reference. It is not deployed and nothing in `site/` uses it.

- `src/dsp.js`, `src/ui.html`: the original engine and page; `build.mjs` inlined one into the other to make `index.html`.
- `engine.test.mjs`: its engine test (run from the repo root with `node legacy/kestrel-v0.2/engine.test.mjs`).

The live app grew from this in `site/` (see the main README).
